# Lab 1 - Hello World (`lab1_hello_world`)

Flutter application implementing **Laboratory Exercise #1: Hello World** (Flutter widgets and the Dart entry point) for DCIT 26 - Application Development and Emerging Technologies.
Author: Joyce Alvarez

## Objectives

- Become familiar with the Flutter development environment.
- Recognize the role of Dart in a Flutter application (`main()`, `runApp()`).
- Use basic Flutter widgets (`MaterialApp`, `Scaffold`, `Center`, and `Text`) to display text and position it on the screen.
- Run a simple Flutter application on a supported target.

## Project Structure

- `lib/main.dart` — Contains `main()`, `runApp()`, `MaterialApp`, `Scaffold`, `Center`, and `Text` displaying `Hello World!` on a light-blue background (`#81D4FA`) with dark, high-contrast text (`#0D2538`).
- `test/widget_test.dart` — Automated widget tests verifying text content, centering, and background styling.

## Running the Project

```bash
flutter pub get
flutter run
```
